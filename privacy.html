Privacy Policy — LUMINA-30 MailBus

Effective date: 2026-10-01

This Privacy Policy describes how the LUMINA-30 MailBus application accesses, uses, stores, and shares Google Workspace Gmail data when the operator authorizes the application through Google OAuth.

1. Google data accessed

LUMINA-30 MailBus requests only the Gmail access needed for its current functions: read-only access to Gmail messages and permission to send email. Depending on the operation, the application may process message metadata, sender and recipient addresses, subject lines, message bodies, thread context, timestamps, and Gmail message or thread identifiers.

2. How Google data is used

Google Workspace data is used only to provide the MailBus functions authorized by the operator, including reading inbound email, maintaining thread context, preventing duplicate or unsafe sends, preparing or evaluating replies, sending approved MailBus messages, recording delivery outcomes, and operating safety controls such as HOLD, STOP, NO_RESEND, deduplication, and rate limits.

3. Local storage and retention

OAuth credentials and operational MailBus data are stored on the operator-controlled local system. Operational records may be retained as needed for continuity, deduplication, safety enforcement, troubleshooting, incident review, and confirmation of sent or uncertain-send states. Gmail content is not published as part of the public LUMINA-30 website.

4. AI-assisted processing

Some MailBus functions may use the OpenAI API to classify, evaluate, or draft email-related content. When such a function is invoked, only data needed for that specific MailBus function may be transmitted to OpenAI as a service provider. LUMINA-30 does not sell Google Workspace user data, use it for advertising, or use it to train or improve a generalized artificial-intelligence model.

5. Data sharing

Google Workspace user data is not sold or transferred to advertising platforms, data brokers, or information resellers. Data is shared only when necessary to provide the authorized MailBus function, for security or abuse investigation, to comply with applicable law, or with the user's explicit consent where such consent is required.

6. Google API Services User Data Policy and Limited Use

LUMINA-30 MailBus's use and transfer of information received from Google Workspace APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Reference: Google Workspace user data and developer policy .

7. Revoking access

The operator can revoke the application's Google account access at any time through the Google Account security settings for third-party connections. Revocation prevents future authorized Gmail API access. Local operational records are handled separately from Google's authorization state.

8. Security

MailBus uses OAuth authorization and local access controls and is designed to fail closed when Gmail authentication is invalid or when a send result is uncertain. Authentication secrets are not intended for publication in the LUMINA-30 public repositories.

9. Contact

Privacy or data-use questions about LUMINA-30 MailBus may be sent to lumina30.reference@gmail.com.

10. Changes to this policy

This policy may be updated when the MailBus data flow, OAuth scopes, service providers, or applicable Google API requirements materially change. The effective date above identifies the published version.
